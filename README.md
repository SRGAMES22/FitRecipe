# FitRecipe 🥗💪

**Receitas Saudáveis + Tracking de Treinos e Macros**  
Biblioteca de receitas com cálculo de macros + registro de treinos e progresso físico.

## Stack

| Camada     | Tecnologia                          |
|------------|-------------------------------------|
| Backend    | Ruby on Rails 7.2 (API) + PostgreSQL + JWT |
| Web        | Next.js 14 (App Router) + Tailwind CSS |
| Mobile     | React Native (Expo) + NativeWind    |
| Temas      | Light / Dark / **Weapon X** (pago)  |

## Funcionalidades Principais

- Biblioteca de receitas com filtros (calorias, proteína, tempo)
- Cálculo de macros por porção
- Registro de treinos
- Progresso físico (peso, medidas)
- Favoritos
- **Temas**: Light / Dark / **Weapon X** (inspirado em Deadpool & Wolverine)
